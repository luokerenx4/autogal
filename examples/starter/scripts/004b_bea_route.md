周六下午四点。你跟着碧河沿着河堤一路走。

她的足球部其实早早就把烧烤架支好了，但她没急着回去。

@bea 这边比那边安静。先溜达一会儿吧。

@narrator 她走在你前面半步，回头看你的次数比看路多。

@bea 你转学过来不到一个月吧？

@bea 习惯吗？

? 你怎么说？
- "还好，挺安静。" -> +bea
- "你这样的吵闹一过来，我就习惯了。" -> +2bea
- "其实挺孤独的。" -> +bea
- "没什么感觉。" -> -bea

她哈哈笑了几声，没接话。

@narrator 走到一座小桥上，她停下来，靠着桥栏。

@bea 你知道我为什么喊你来吗？

? 你怎么回？
- "因为我刚转学过来比较孤独？" -> +bea
- "因为社团需要新人？" -> -bea
- "因为你想跟我多聊几句。" -> +2bea

@bea 嗯——三分对，七分错。

@bea 我看人挺准的。你这种安静的人，往往心里有事。

@bea 我喜欢有点事的人，没事的人没意思。

? 你怎么应？
- "你也挺有意思。" -> +alice
- "你的'有事'范围太广了。" -> +bea
- "那你心里有什么事？" -> +2bea

@narrator 她沉默了一会儿。然后笑了笑。

@bea 等会儿吃饱了告诉你。

@bea 走吧，他们应该都饿坏了。

@narrator 你和她一起走向河滩的火光。

@narrator 烤肉的烟混着她身上的草地气味。

@bea （远远地朝队友挥手）来啦——！

@bea （回过头小声跟你说）我刚刚说的"有事的人"，包括你。

@bea 别告诉别人。
